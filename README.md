# Cosplay Archive

Личный каталог косплей-сетов и фотографий. Приложение работает локально: данные хранятся в IndexedDB браузера, изображения автоматически сжимаются в WebP при загрузке. Дополнительно доступна синхронизация каталога и фото с Google Drive (необязательно).

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте папку в VS Code.
3. Запустите через расширение Live Server или выполните `python -m http.server 8000`.
4. Откройте `http://localhost:8000`.

## Важно

- Это локальная версия: данные сохраняются в IndexedDB текущего браузера и устройства.
- Для переноса на другое устройство используйте экспорт резервной копии и импорт на другом устройстве либо синхронизацию с Google Drive (см. ниже).
- Очистка данных сайта/браузера может удалить архив. Делайте резервные копии.
- Облачная синхронизация работает только после настройки OAuth Client ID и включается вручную.

## Синхронизация с Google Drive

Приложение умеет складывать каталог и фотографии в папку `Cosplay Archive` на Google Drive. Для ПК и телефона используется один и тот же аккаунт и один и тот же Client ID — так каталог подтягивается на всех устройствах.

### Что нужно подготовить (один раз)

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. В разделе **APIs & Services → Library** включите **Google Drive API**.
3. В разделе **APIs & Services → OAuth consent screen** заполните основные поля и добавьте себя в **Test users** (режим «Testing» подходит для личного использования).
4. В разделе **APIs & Services → Credentials** создайте **OAuth client ID** типа **Web application**.
5. В поле **Authorized JavaScript origins** добавьте адрес, с которого открываете сайт:
   - для локального запуска: `http://localhost:8000` (или `http://127.0.0.1:8000`);
   - для телефона — адрес, по которому открыт сайт на телефоне.
6. Скопируйте полученный **Client ID**.

### Подключение

1. Впишите Client ID в `js/config.js` в поле `drive.clientId`.
2. Откройте сайт и нажмите в подвале **«Подключить Google Drive»**, разрешите доступ.
3. Дальше каталог синхронизируется автоматически после изменений, а кнопка **«Синхронизировать»** запускает обмен вручную.

Файлы на Drive: манифест `archive.json` и папка `photos` с отдельными снимками. Удаления синхронизируются через «надгробия» в localStorage, поэтому удаление с одного устройства убирает запись и на остальных.


## Содержимое

- `index.html` — интерфейс.
- `css/style.css` — оформление.
- `js/config.js` — настройки: обработка изображений, лимиты, версия базы и параметры Google Drive (`clientId`).
- `js/app.js` — вся логика: каталог, IndexedDB, сжатие фото, резервные копии, синхронизация.
- `js/drive.js` — модуль работы с Google Drive (авторизация, загрузка/скачивание фото, манифест).
- `О_ПРОЕКТЕ.md` — актуальное описание проекта.
- `Идеи развития Cosplay Archive.md` — идеи будущих улучшений.

## Возможности

- **Модели** — косплеерши: имя, ссылка на источник, теги, заметки, обложка из сетов.
- **Сеты** — фотосеты модели: название, персонаж, дата, личная оценка (1–5), описание, теги.
- **Поиск.** Модели — по имени, тегам и заметкам. Сеты — по названию, персонажу, описанию, тегам и имени модели.
- **Сортировки.** Модели: «Недавно изменённые», «По имени», «По количеству сетов». Сеты: «Сначала новые», «Сначала старые», «Больше фотографий», «По рейтингу», «По персонажу».
- **Теги.** Вводите через запятую, например `#finalfantazy, #genshinimpact, #anime`. Символ `#` можно не вводить — сайт добавит его сам. На странице «Сеты» теги показываются кнопками-фильтрами.
- **Избранное** для сетов, случайный сет и статистика в подвале.
- **Фотографии.** К сету добавляется несколько фото; при загрузке они уменьшаются по длинной стороне до 2200 px и конвертируются в WebP (качество ≈0.88).
- **Резервная копия.** Экспорт в JSON вместе с изображениями и импорт такого файла.
- **Синхронизация с Google Drive.** Каталог и фото складываются в облако и подтягиваются на других устройствах под тем же аккаунтом.
- **Просмотр.** Окно сета и полноэкранный просмотр фотографий с навигацией (стрелки, счётчик).
