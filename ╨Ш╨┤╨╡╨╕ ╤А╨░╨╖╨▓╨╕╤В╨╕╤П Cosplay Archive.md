# Идеи развития Cosplay Archive

Этот файл — список возможных улучшений. Уже реализованные функции отмечены отдельно.

## Уже предусмотрено в текущей версии
- [x] Пользовательские хэштеги вроде `#finalfantazy`.
- [x] Фильтр сетов по тегам через кнопки-теги на странице «Сеты».
- [x] Сортировки: модели — «Недавно изменённые», «По имени», «По количеству сетов»; сеты — «Сначала новые/старые», «Больше фотографий», «По рейтингу», «По персонажу».
- [x] Добавление новых фотографий к существующему сету без удаления старых.
- [x] Сжатие изображений в WebP перед загрузкой (до 2200 px, качество 0.88).
- [x] Избранное для сетов, поиск и полноэкранный просмотр галереи.
- [x] Личная оценка сета (1–5).
- [x] Резервное копирование и восстановление (JSON с изображениями).
- [x] Синхронизация с Google Drive: каталог и фото в облаке на нескольких устройствах с учётом удалений.

## Рекомендуемые следующие улучшения
1. **Именованные подборки:** группы сетов из разных моделей в одной коллекции.
2. **Редактирование хэштегов:** переименование тега сразу во всех сетах, объединение дублей и удаление неиспользуемых тегов.
3. **Массовая загрузка:** перетаскивание множества изображений и выбор целевого сета.
4. **Дубликаты:** поиск одинаковых изображений и похожих файлов.
5. **Фильтры:** по персонажу, дате добавления, наличию заметок и избранному.
6. **Приоритетные сеты:** закрепление или отметка важных сетов поверх остальных.
7. **Адаптация для телефона:** удобное управление каталогом с небольшого экрана.
8. **Импорт из старой версии:** перенос профилей и изображений из локального каталога или JSON-резервной копии.
9. **Развитие синхронизации:** фоновый режим, ручное разрешение конфликтов и выбор папки на Google Drive.

## Приоритет
Сначала удобство повседневного использования (подборки, массовая загрузка и управление тегами), затем фильтры и адаптация для телефона. Для синхронизации — постепенное улучшение надёжности и разрешение конфликтов.
