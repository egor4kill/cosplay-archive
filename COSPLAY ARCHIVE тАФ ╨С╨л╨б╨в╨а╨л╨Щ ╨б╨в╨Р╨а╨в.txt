COSPLAY ARCHIVE — БЫСТРЫЙ СТАРТ

1. Распакуй архив в отдельную папку.
2. Открой О_ПРОЕКТЕ.md, чтобы узнать, что входит в проект и какие есть ограничения.
3. Запусти через Live Server либо в папке проекта выполни:
   python -m http.server 8000
4. Открой http://localhost:8000

Это локальная сборка: данные хранятся в IndexedDB браузера. Для переноса на другое устройство используй экспорт и импорт резервной копии. По желанию можно включить синхронизацию с Google Drive: укажи OAuth Client ID в js/config.js и нажми в подвале «Подключить Google Drive» (подробности — в README.md).

ХЭШТЕГИ: указывай их в поле «Теги», например #finalfantazy, #genshinimpact, #anime. На странице «Сеты» теги показываются кнопками — по нажатию каталог фильтруется.
ФОТО: фотографии добавляются к сету в форме сета; при загрузке они сжимаются в WebP (до 2200 px, качество 0.88).
Перед очисткой браузера делай экспорт резервной копии.

Актуальное описание проекта поддерживается в О_ПРОЕКТЕ.md.
